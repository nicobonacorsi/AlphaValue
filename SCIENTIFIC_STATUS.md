# Scientific scope

Certified Alpha Capacity studies statistical learning before an opportunity decays. The mathematical guarantees apply under the likelihood, observation, uncertainty and reward assumptions stated in the paper. A joint likelihood includes the signal's contribution even when that signal is predictable.

The sharp near-frontier law is asymptotic. Feasible two-look policies and numerical checks illustrate the analytical results. Translating information capacity into cash value requires the stated uniform conditions on the reward family.

The funding illustration measures descriptive associations with subsequent signed funding rates. The event table, source-input identities, extraction rule and statistical calculation are supplied for reproduction. Execution, hedge, financing and collateral costs lie outside this empirical estimand; no confirmatory trading-profit validation is claimed.

The software tests verify the documented numerical and interface behavior. The reproduction command recomputes the funding summaries from the event table and renders the four manuscript figures. Times New Roman is used when available; STIX, bundled with Matplotlib, provides an explicit portable alternative.
